# TradeCheck 首轮试用指南

当前公开版为 **v0.1.2 alpha**。这轮试用主要确认安装是否顺利、页面流程是否容易理解，
以及已声明支持的模板能否完成预览、核对、批量命令和报告生成。试用结果用于发现问题，
不代表工具已经通过真实业务准确率验证。

## 开始试用

1. 按 README 的快速开始步骤安装并启动 TradeCheck。
2. 先使用仓库虚构样例 `samples/A/normal_invoice.xlsx` 和
   `samples/A/normal_packing.xlsx` 完成一次完整流程。
3. 如果方便，再用模板 B 的 `samples/B/normal_invoice.xlsx` 和
   `samples/B/normal_packing.xlsx` 重复一次。
4. 可选：在仓库根目录运行
   `tradecheck batch --manifest samples/batch-manifest.example.json`，确认虚构清单中的两组
   样例都完成且退出码为 0。
5. 记录是否能完成文件选择、字段预览、核对、批量命令和 HTML 报告生成，以及任何报错或难以理解的
   提示。
6. 停止服务后，按自己的设备和组织要求清理本地生成的报告和试用文件。

## 数据保护

- 首轮公开试用请使用仓库中的虚构样例。
- 不要在 Issue、PR、聊天或公开截图中提交客户名称、订单号、发票号、价格、银行信息、
  联系人、签章、原始工作簿或 HTML 报告。
- HTML 报告可能包含输入字段。即使工作簿未上传，分享报告也可能泄露单据内容。
- 若本地尝试自己的资料，请只在你控制的设备上操作，并自行检查和清理生成的文件；不要
  将真实资料交给维护者排查。

## 试用边界

TradeCheck 目前只支持 README 所列的两种 Excel 布局，不支持 PDF、OCR、公式重算、多币种
换算或复杂多工作表场景。对于无法确认的结果，应按页面提示人工复核，不要把“未发现差异”
理解成单据或交易已经获得业务批准。
